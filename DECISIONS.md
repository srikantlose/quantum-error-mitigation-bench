| 2026-10-06 | Config tests location | Config load and validation tests live in `tests/test_seeds.py` alongside the seed tests. | Keeps the eight test files listed in §4; Phase 1 groups both checks. |

| 2026-10-06 | Transpiler seed | `Executor.run` takes an optional `transpile_seed`; the sweep passes `derive_seed("transpile", n, L, noise, seed, purpose)` and a direct call falls back to `derive_seed("transpile", seed)`. | §9's `run` signature has no slot for the §6 transpiler seed. |
| 2026-10-06 | `E_noisy_exact` | Computed in the core sweep by `Executor.exact_noisy_probs` (density matrix, then `A_true @ p_gate`). | The column is in the §12 schema; it uses no shots or RNG, so it cannot change any other result. |
| 2026-10-06 | Smoke output location | `run_sweep.py --smoke` writes to `results/smoke/` (git-ignored); `--out` overrides any output directory. | `smoke.yaml` shares `output.dir: results` with the full config, so a smoke run would otherwise overwrite the full sweep's `runs.csv`. |
| 2026-10-06 | Reproducibility check | The test compares every `runs.csv` column except `time_quantum_s` and `time_classical_s` as exact strings, plus byte equality of all counts, circuit and calibration files. CSVs use `float_format="%.10g"` and `lineterminator="\n"`; JSON uses `sort_keys=True`. | §0.5 asks for a byte-identical file but §12 excludes wall-clock columns; pandas would write `\r\n` on Windows. |
| 2026-10-06 | `extrapolation_out_of_range` encoding | Stored as 0/1 for `zne` and `zne_rem`, empty otherwise. | A boolean column with NaN becomes an object column; 0/1 sums directly into out-of-range counts. |
| 2026-10-06 | `rem_negative_mass` for `zne_rem` | Mean of the negative mass over the three REM-corrected scale factors; `rem_condition_number` is cond(A) of the shared matrix. | §12 defines one column per row while `zne_rem` inverts A three times. |
| 2026-10-06 | Overhead and timing accounting | `total_shots` = shots × circuits + `calibration_shots` × 2^n; `time_classical_s` times each method's own post-processing from counts (assignment matrix build, inversion, extrapolation). | Matches the §11 formulas when `calibration_shots = shots = 1024` and stays correct if they differ. |
| 2026-10-06 | Raw counts file | `results/raw/counts/{run_id}.json` holds the base, folded (`scale_counts`), calibration and noiseless-reference counts. | §12 asks for all counts used; the noiseless reference is shared by the three noise levels of an instance and is repeated in each. |
