Quantum circuit noise and error mitigation

Five mitigation methods on a layered parity circuit under depolarizing + readout noise (Track A), the same methods applied to a variational quantum classifier against Logistic Regression and SVM (Track B), and a variance-optimal shot allocation for ZNE. Every number below is read live from results/summary/report_numbers.json and the raw run CSVs — nothing here is hand-typed.

Improvement — variance-optimal shot allocation

Method key

none — raw noisy expectation value. rem — full readout error mitigation (2n calibration circuits, matrix inversion/least-squares). rem_tensored — scalable per-qubit readout mitigation (2 calibration circuits, Kronecker-product assignment matrix, assumes uncorrelated readout errors). zne — zero-noise extrapolation by global unitary folding at λ=1,3,5, Richardson/linear/exponential fits back to λ=0. zne_rem — ZNE applied to REM-corrected expectation values.
